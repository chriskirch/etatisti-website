6. Etatisti Autoloop (Google API use)

Etatisti Autoloop is a private tool used only by its owner to upload videos to the owner's own Etatisti YouTube channel. It is not offered to the public and has no other users.

  • Data accessed: the app requests only the Google OAuth scope youtube.upload for the owner's own channel. It does not access data of any other Google user.
  • Storage: the OAuth token is stored only on the owner's private server. It is not shared with, transferred to or sold to third parties.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.

Etatisti Autoloop's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
